## Какие навыки подтверждаются

| № | Риск / навык | Проверяемый контроль |
|---:|---|---|
| 1 | DOM injection / XSS | Вывод текстом, allow-list полей, ограничения длины |
| 2 | Небезопасное хранение состояния | Локальное состояние не используется как авторизационное решение |
| 3 | Утечка через URL | Не передавать чувствительные поля в URL |
| 4 | Внешняя навигация | Явно маркировать внешние переходы; noopener для нового окна |
| 5 | Ошибочная security-атрибуция | Scope/disclaimer в SECURITY.md |

## Артефакты этого кейса

- `SECURITY.md` — scope и ограничения;
- `EVIDENCE.md` — карта доказательств;
- `security/docs/threat-model.md` — модель угроз;
- `security/tests/manual-security-checklist.md` — ручной сценарий проверки;
- Для углублённого исполняемого доказательства см. опорный практический кейс `index1`; текущий кейс не притворяется отдельным pentest-проектом.

## Не доказывается

- доступ к системам реальной организации;
- эксплуатация уязвимостей внешних сервисов;
- промышленная безопасность инфраструктуры;
- соответствие конкретному отраслевому стандарту без отдельного аудита.
