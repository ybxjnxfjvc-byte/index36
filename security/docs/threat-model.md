# Mini threat model — index36

## Scope

Публичный учебный кейс `Колледж добрых дел — система обучения`, его статические файлы, браузерная сессия, локальное состояние и только те локальные лабораторные сервисы, которые лежат в этом репозитории.

## Assets

1. Целостность учебного контента и логики тренажёра.
2. Данные, вводимые посетителем в демонстрационные формы.
3. Состояние прохождения/результата, если оно сохраняется локально.
4. Конфигурация и секреты локальных лабораторных сервисов.
5. Целостность содержимого репозитория и публикации GitHub Pages.

## Trust boundaries

`visitor → browser DOM → local state → optional local lab`

`developer workstation → Git → repository → GitHub Pages`

## Risks and controls — Web / DOM / недоверенный ввод

| ID | Risk | Scenario | Control |
|---|---|---|---|
| T1 | DOM injection / XSS | Недоверенное имя, подразделение или свободный текст попадает в HTML | Вывод текстом, allow-list полей, ограничения длины |
| T2 | Небезопасное хранение состояния | Прогресс/ответы в localStorage воспринимаются как доверенный источник | Локальное состояние не используется как авторизационное решение |
| T3 | Утечка через URL | Пользовательские данные попадают в query string | Не передавать чувствительные поля в URL |
| T4 | Внешняя навигация | Ссылка открывает внешний ресурс без явной границы доверия | Явно маркировать внешние переходы; noopener для нового окна |
| T5 | Ошибочная security-атрибуция | Учебный кейс принимают за аудит компании | Scope/disclaimer в SECURITY.md |

## Residual risk

Статический публичный кейс не превращается в промышленное приложение только из-за наличия security-документации. Там, где отсутствует сервер, серверные меры показаны только в локальных учебных лабораториях и не выдаются за часть реальной инфраструктуры компании.
